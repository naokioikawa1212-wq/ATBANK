# Makuake 商品選定レポート（2026年版）

作成日: 2026-06-26

## 1. 選定方針（依頼条件の整理）

| 条件 | 内容 | 本レポートでの扱い |
|------|------|--------------------|
| 仕入れ先 | 原則アリババ1688（1688.com） | 各候補に1688検索キーワードを付与 |
| 新規性 | 日本のAmazonで未販売であること | 「Amazon.co.jp未販売チェック」欄＋検証手順を記載 |
| 参入障壁回避 | コンセント（電気）・食品など障壁の高いものは避ける | 法規制マトリクスで除外ジャンルを明確化 |

### 1-1. Makuakeの勝ちパターン（2025年実績）

2025年のMakuakeは応援購入総額 約152億円・約104万人・5,042件。
最も総額が集まったジャンルは **①バッグ・ファッション小物**、続いて **②寝具（マットレス・掛け布団）**、**③スマホ・タブレット・PCアクセサリ** が安定上位。
→ 「生活の質を上げる」「既存品の不満を1点突破で解決する」アイデア商品が刺さりやすい。

## 2. 参入障壁マトリクス（除外ジャンルの根拠）

依頼の「コンセント・食品」を、関連する日本の法規制まで広げて整理。**以下に該当するジャンルは原則除外**します。

| 障壁 | 該当する法規制 | 避けるべき商品例 |
|------|----------------|------------------|
| コンセント・電源 | 電気用品安全法（PSE） | ACアダプタ、充電器、電源タップ、家電 |
| バッテリー内蔵 | PSE（リチウム電池）／ PSEマーク・輸送規制 | モバイルバッテリー、電動ガジェット |
| 無線・通信 | 電波法（技適マーク） | Bluetooth/WiFi機器、ワイヤレスイヤホン、スマートウォッチ |
| 食品・口に触れる | 食品衛生法 | 食品、サプリ、**食器・カトラリー・水筒の口部** |
| 肌・効能 | 薬機法 | 化粧品、美容機器、医療類似器具、マッサージ機 |

> 重要: 「コンセント」を避けても **電池内蔵・Bluetooth搭載ガジェット** は別の認証（PSE/技適）が必要になります。本レポートの候補は **電源・電池・無線・食品接触・肌効能のいずれも持たない「非電気・非認証」カテゴリ** に絞り込みました。これが今回の最大のリスク回避ポイントです。

## 3. 推奨商品カテゴリ（6候補）

各候補は「Makuake上位ジャンルとの親和性」「1688での調達しやすさ」「無認証で出せる」の3条件を満たすものに限定。

### 候補① 多機能ミニ財布 / コンパクト長財布
- **Makuake親和性**: ★★★（最上位ジャンル「バッグ・ファッション小物」。財布カテゴリは常に売れ筋）
- **1688検索キーワード**: `迷你钱包`, `卡包钱包一体`, `磁吸钱包`, `真皮短钱包`
- **差別化の切り口**: 「お札がスルスル出る独自構造」「カード一括引き出し」など機構で1点突破。革・素材で高見え。
- **Amazon.co.jp未販売チェック**: ノーブランド財布は飽和。**独自の開閉機構・素材の組み合わせ**でAmazon未掲載の構成を狙う（同一構造のASINが無いことを確認）。
- **障壁**: なし（無認証）。原価が安く利益率を取りやすい。

### 候補② 快眠グッズ（非電気）: 構造系まくら / 着る毛布 / 高機能アイマスク
- **Makuake親和性**: ★★★（2025年#2ジャンル「寝具」）
- **1688検索キーワード**: `人体工学枕`, `穿戴式毛毯`, `3d立体眼罩`, `颈椎枕`
- **差別化の切り口**: 形状・素材（低反発、そば殻代替、遮光率100%など）。電気を使わない快眠ソリューション。
- **Amazon.co.jp未販売チェック**: 汎用枕は飽和のため、**特殊形状＋ストーリー（整体師監修など）** で未販売構成を作る。
- **障壁**: なし。ただし「肩こり改善」等の効能表現は薬機法に触れるため **訴求は『睡眠の質』『快適さ』に限定**。

### 候補③ EDC文具・デスクガジェット（機構系・非電気）
- **Makuake親和性**: ★★★（#3「PC・スマホアクセサリ」周辺。Makuakeはギミック文具が鉄板）
- **1688検索キーワード**: `黄铜文具`, `磁吸笔`, `桌面收纳`, `金属书签`, `减压玩具 金属`
- **差別化の切り口**: 真鍮・チタン・マグネット機構など「触って楽しい」質感。ペン、ペーパーウェイト、メタルパズル等。
- **Amazon.co.jp未販売チェック**: 金属加工系はOEMで独自デザイン化しやすく、未販売構成を作りやすい。
- **障壁**: なし（無認証）。軽量で国際送料も安い。

### 候補④ ペット用品（非電気）
- **Makuake親和性**: ★★☆（ペット市場拡大。給水・スローフード・お出かけ系が定番）
- **1688検索キーワード**: `宠物慢食碗`, `猫咪逗猫`, `宠物背包 透气`, `狗狗牵引`
- **差別化の切り口**: 早食い防止フードボウル、構造で工夫したリュード型キャリー等。飼い主の不満を解決。
- **Amazon.co.jp未販売チェック**: デザイン・機能の独自組み合わせで差別化。
- **障壁**: なし。ただし口に触れる給水・給餌の **接触素材** は安全性に配慮（食品衛生法のグレーゾーンを避けるなら非接触機構を選ぶ）。

### 候補⑤ アウトドア非燃焼ギア（焚き火台以外の機構・布物）
- **Makuake親和性**: ★★☆（キャンプ・アウトドアは根強い。軽量・コンパクト訴求が刺さる）
- **1688検索キーワード**: `折叠收纳箱`, `户外折叠桌`, `露营挂架`, `便携吊床`
- **差別化の切り口**: 折りたたみ機構・超軽量・収納性。**ガス/電気を使わない** 道具に限定。
- **Amazon.co.jp未販売チェック**: 既存品との寸法・素材・機構の差で未販売構成を狙う。
- **障壁**: なし。※燃焼器具（バーナー等）・電気ランタンは別リスクのため除外。

### 候補⑥ 自転車・モビリティアクセサリ（非電気）
- **Makuake親和性**: ★★☆（ガジェット好き層と親和。スマートな収納・固定具が定番）
- **1688検索キーワード**: `自行车工具`, `单车收纳包`, `车把固定`, `便携打气`（※電動ポンプは除外）
- **差別化の切り口**: マルチツール、フレームバッグ、固定機構など機械的な工夫。
- **Amazon.co.jp未販売チェック**: 機構の独自性で差別化。
- **障壁**: なし（手動・非電気のものに限定。電動空気入れ・ライトのうち充電式はPSE対象になるため除外）。

## 4. Amazon.co.jp 未販売チェックの手順（必須・手動）

> 本レポートのカテゴリ判断はWeb調査ベースです。**個別商品（最終1点）の「Amazon未販売」確定は、必ず以下の手動検証で確認してください。** 自動ツール（US-only検索）だけでは断定できません。

1. **画像検索**: 1688の商品画像をGoogle画像検索／Amazon.co.jpアプリの「カメラ検索」にかけ、同一OEM品の出品有無を確認。
2. **キーワード検索**: 日本語の想定商品名＋「ノーブランド」でAmazon.co.jpを検索。同一構造のASINが無いことを確認。
3. **相乗り回避**: 完全一致のASINが無く、かつ自分が「型番・ブランド・パッケージ」を変えてオリジナル化できるかを確認（Makuakeは"国内未発売"が出品条件のため、ここが必須）。
4. **キーワード深掘り**: 関連語（素材名・機構名）でも複数回検索し、別名で既出していないか確認。
5. **メーカー直販OEM**: 1688で工場直販（OEM可）ショップを選び、ロゴ・色・パッケージを変更して独自商品化する。

## 5. 次のアクション

1. 候補①〜③（Makuake上位ジャンル直結・無認証）を優先リサーチ対象とする。
2. 1688で上記キーワードから各3〜5商品をピックアップし、第4章の手順でAmazon.co.jp未販売を1点ずつ確定。
3. 確定商品について、最小ロット見積り・サンプル取り寄せ・原価/利益シミュレーションへ進む。
